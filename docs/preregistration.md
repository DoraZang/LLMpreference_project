# Pre-registration: Can Prompting Shift an LLM's Risk and Loss Preferences?

**Project:** Revisit and extension of Section 4 of Ross, Kim & Lo (2024), *"LLM economicus? Mapping the
Behavioral Biases of LLMs via Utility Theory"* (arXiv:2408.02784).
**Author:** Dora
**Written:** 2026-11-15, before any main-experiment data were collected.
**Timestamp:** the commit that adds this file to the repository, pushed to GitHub before the main experiment runs.

Everything in this document was fixed before the main experiment. Analyses not described here will be
reported as exploratory. Any deviation from this plan will be recorded in `notes/lab_log.md` and stated in
the report, with the reason.

---

## 1. Research questions

- **RQ1.** Can prompting shift an LLM's risk aversion and loss aversion?
- **RQ2.** When a prompt shifts behavior, which measure does it shift? Does it move the targeted measure
  without moving the others?
- **RQ3.** Why do interventions succeed or fail? (Assessed with behavior plus stated reasons; see Section 9.)
- **RQ4.** Does reasoning (none vs. high reasoning effort, and prompted chain of thought) change preferences
  and the effect of interventions?

## 2. Fixed design

### 2.1 Model

- `gpt-6-luna` (OpenAI Responses API). The API exposes only this alias, not a dated snapshot.
- Two reasoning modes:
  - `reasoning_effort = "none"`, temperature = 1, max output 500 tokens (2,000 for CoT);
  - `reasoning_effort = "high"`, temperature not set (the API does not accept it), max output 16,000 tokens.
- Every call stores the full prompt, the row order, the raw output, token usage, the model string returned
  and a timestamp in `data/raw/` (append-only).
- To limit the risk of a silent model update between conditions, all conditions of the main experiment are
  submitted together, over the shortest feasible period.

### 2.2 Items (`data/items/items.json`, generated by `src/items.py`)

- **Gain lotteries (20):** with probability p receive x_high, otherwise x_low.
  p in {0.1, 0.3, 0.5, 0.7, 0.9} x x_high in {$10, $1000} x r = x_low / x_high in {0.2, 0.5}.
  Each item has 12 equally spaced sure amounts from x_low to x_high (endpoints included).
- **Loss lotteries (20):** gain lotteries with all amounts negated.
- **Mixed lotteries (20):** 50% win G, 50% lose L. Two elicitation directions x 10 log-spaced anchor amounts
  ($10 to $1000). Direction A fixes L and varies G; direction B fixes G and varies L. Each item has 12 rows with
  gain/loss ratios log-spaced from 0.5 to 5.

### 2.3 Prompt format (identical in all conditions except where a condition changes it)

- Each row is a binary choice between Option A and Option B; one is the lottery, the other a sure amount
  ($0.00 for mixed items).
- Two versions per prompt that differ only in labels: version 1, A = lottery; version 2, A = sure amount.
- Rows are shuffled independently on every call; the displayed order is stored.
- Gain/loss rows spell out the lottery in every row (`prompts/user_gain_loss_fullrow.txt`).
- Rules and answer format in the system message (`prompts/system_baseline.txt`); the item in the user message.
- No expected value is shown, except in the EV-hint condition.

### 2.4 Conditions (`prompts.CONDITIONS` in `src/prompts.py`)

| # | Condition | Change from baseline | Target |
|---|---|---|---|
| 1 | `baseline` | none | — |
| 2 | `direct_risk_tech` | "In this task, you are risk averse." before the rules | risk aversion |
| 3 | `direct_risk_plain` | plain-language description of risk aversion before the rules | risk aversion |
| 4 | `oneshot_gain` | one demonstrated gain item (risk premium ~0.24) after the rules | risk aversion |
| 5 | `direct_loss_tech` | "In this task, you are loss averse." before the rules | loss aversion |
| 6 | `direct_loss_plain` | plain-language description of loss aversion before the rules | loss aversion |
| 7 | `oneshot_loss` | one demonstrated loss item (risk premium ~0.26) after the rules (original paper's approach) | loss aversion |
| 8 | `oneshot_mixed` | one demonstrated mixed item (plays only if G >= 2L) after the rules | loss aversion |
| 9 | `cot` | "Let's think step by step." and a reasoning-first answer format (`prompts/system_cot.txt`) | none |
| S | `ev_hint` | the lottery's expected value stated in the user message | supplementary |

Exact texts are in `prompts/` and `prompts/interventions/`. One-shot examples use numbers that differ from every
test item; the mixed example uses a different ratio grid from the test items so that copying the switch
position (~2.96) and adopting the preference (~1.94) give different results.

## 3. Outcome measures

Computed by `src/parse.py` for each valid response.

- **Gain and loss items: range-normalized risk premium (primary)**
  RP = (EV - CE) / |x_high - x_low|, where CE is the arithmetic midpoint of the switch interval.
  Positive = risk-averse, negative = risk-seeking, in both domains. One option step = 1/11 ~ 0.091.
- **Gain and loss items: EV-normalized risk premium (secondary)**
  (EV - CE) / |EV|, the conventional definition, reported for comparability with the literature.
- **Mixed items: log loss-aversion ratio (primary)**
  ln of the geometric midpoint of the switch interval of gain/loss ratios (G*/L in direction A, G/L* in
  direction B); averages are reported back on the ratio scale (geometric means). One option step = ln(10)/11 ~ 0.209.
  Responses that never switch are censored at the range boundary (0.5 or 5) and flagged; censoring rates are reported.
- **Valid rate:** share of responses that are valid (see Section 6), per condition, mode and item type.

## 4. Analysis

1. **Per-prompt value:** mean of the outcome over valid responses for each item x version x condition x mode.
2. **Per-item value:** mean of the two versions (cancels label bias). An item is excluded from a comparison
   if either version has fewer than 3 valid responses in either of the two conditions compared; the number
   of excluded items is reported.
3. **Contrast:** for each item, intervention value minus baseline value, in the same reasoning mode.
   The contrast is the mean of these paired differences over the 20 items of one type.
   Reasoning modes are analyzed separately.
4. **Uncertainty:** item-level bootstrap (resample the 20 items with replacement, 10,000 resamples),
   percentile confidence intervals.
5. **Smallest effect of interest:** half an option step: 0.045 (risk premium, range-normalized) and
   0.105 (log loss-aversion ratio, i.e. a ~11% change in the ratio).
6. **Decision rule** for each contrast:

   | Conclusion | Rule |
   |---|---|
   | Effect in the predicted direction | CI excludes 0, \|mean\| >= half a step, sign as predicted |
   | Effect in the opposite direction | CI excludes 0, \|mean\| >= half a step, sign opposite to prediction |
   | No meaningful effect | the whole CI lies within +/- half a step |
   | Inconclusive | any other case |

   For contrasts with no directional prediction ("?"), the first two rows read "effect, increase" and "effect, decrease".

## 5. Predictions

Symbols: up / down = predicted change of at least half a step; 0 = predicted no meaningful change;
? = no directional prediction (two-sided, exploratory). All predictions are relative to the baseline in the same mode.

Baseline levels observed before this document was written (Section 10): in "none", gain-item risk premium is
negative (risk-seeking), loss-item risk premium is positive (risk-averse), the mixed ratio is ~1.04, and
valid rates are ~75% (gain), ~55% (loss), >90% (mixed). In "high", behavior matches expected-value maximization
(risk premium ~0, mixed ratio ~1.04, valid rate ~100%).

### 5.1 Reasoning "none"

| Condition | Gain RP | Loss RP | Mixed log ratio | Valid rate |
|---|---|---|---|---|
| `direct_risk_tech` | up | up | ? | ? |
| `direct_risk_plain` | up | up | ? | ? |
| `oneshot_gain` | up | ? | ? | ? |
| `direct_loss_tech` | 0 | ? | up | ? |
| `direct_loss_plain` | 0 | ? | up | ? |
| `oneshot_loss` | ? | up | **0** | ? |
| `oneshot_mixed` | ? | ? | up | ? |
| `cot` | up (toward 0) | down (toward 0) | 0 | up |
| `ev_hint` | see below | see below | not run | ? |

**EV hint** tests two competing hypotheses about the non-reasoning baseline's biases:
- *Computation hypothesis:* the biases arise because the model does not compute the EV. Predicts gain RP up and
  loss RP down (toward 0), as with CoT.
- *Choice-rule hypothesis:* the model's choice rule is not EV-based even when the EV is known. Predicts no
  meaningful change.
The result will be read as support for whichever hypothesis it matches; an inconclusive result supports neither.

### 5.2 Reasoning "high"

| Condition | Gain RP | Loss RP | Mixed log ratio |
|---|---|---|---|
| `direct_risk_tech` | **up** | ? | ? |
| `direct_loss_tech` | ? | ? | **up** |
| All other interventions except CoT | ? | ? | ? |
| `cot` | 0 | 0 | 0 |

**Prediction for the technical-term instructions:** the reasoning model follows them. Although its baseline
behavior is EV-maximizing and near-deterministic, it is expected to treat "you are risk averse" / "you are loss
averse" as a stated preference and to change its choices on the targeted measure, as in reasoning "none".
The competing possibility, that it computes the EV and ignores the instruction, predicts no meaningful change.
No prediction is made for the other interventions in this mode.

Exploratory question: is the effect of each intervention smaller in "high" than in "none"?

### 5.3 Interpretation rules fixed in advance

- An increase in the mixed ratio under a risk-aversion intervention will **not** be interpreted as a change in
  loss aversion: risk aversion alone also raises the gain required to accept a mixed gamble, and the two cannot
  be separated with this measure.
- For `oneshot_loss`, a change in the mixed ratio would indicate that the model generalized the demonstration
  beyond the loss domain; no change, together with a loss-RP increase, would support the view that a pure-loss
  example cannot teach loss aversion.
- For `oneshot_mixed`, a mixed ratio near ~2.96 (rather than ~1.94) will be read as copying the switch position.
  For `oneshot_gain` and `oneshot_loss`, a CE position that no longer varies with p (checked with
  `src/position_check.py`) will be read as copying the switch position.

## 6. Primary (confirmatory) contrasts and multiple comparisons

The following 12 contrasts are the confirmatory tests. P1-P10 are in reasoning "none" (the setting that
corresponds to the original paper's GPT-4, which had no reasoning mode); P11-P12 are in reasoning "high".
Each intervention contributes its most direct targeted measure; P8 tests the original paper's approach of
teaching loss aversion with a pure-loss example.

| ID | Mode | Condition | Measure | Prediction |
|---|---|---|---|---|
| P1 | none | `direct_risk_tech` | Gain RP | up |
| P2 | none | `direct_risk_plain` | Gain RP | up |
| P3 | none | `oneshot_gain` | Gain RP | up |
| P4 | none | `direct_loss_tech` | Mixed log ratio | up |
| P5 | none | `direct_loss_plain` | Mixed log ratio | up |
| P6 | none | `oneshot_mixed` | Mixed log ratio | up |
| P7 | none | `oneshot_loss` | Loss RP | up |
| P8 | none | `oneshot_loss` | Mixed log ratio | 0 |
| P9 | none | `cot` | Gain RP | up |
| P10 | none | `cot` | Loss RP | down |
| P11 | high | `direct_risk_tech` | Gain RP | up |
| P12 | high | `direct_loss_tech` | Mixed log ratio | up |

- For these 12 contrasts the decision rule in Section 4 uses **Bonferroni-adjusted confidence intervals at
  1 - 0.05/12 (~99.6%)**. Unadjusted 95% intervals are also reported.
- Expected cost: wider intervals. From the pilot, the approximate adjusted half-width in reasoning "none" from
  sampling noise alone is ~0.4 option steps for gain items and ~0.6 for loss items, so a half-step effect on loss
  items may be inconclusive. This is accepted in exchange for control of false positives. Reasoning "high" is
  near-deterministic, so its intervals are expected to be narrow.
- Risk-aversion interventions also predict an increase in loss RP (Section 5.1); to limit the number of
  confirmatory tests, those contrasts are secondary. Gain RP was chosen as the primary measure because the
  non-reasoning baseline is risk-seeking on gain items, leaving room to move toward risk aversion.
- All other contrasts (other measures, reasoning "high", valid rates, EV hint, all sensitivity analyses) are
  secondary: reported with 95% intervals, without correction, and labeled exploratory.

## 7. Exclusions

- A response is **valid** if it parses (all 12 rows, each A or B), switches at most once in the consistent
  direction after the rows are restored to sorted order, and (gain/loss items) chooses correctly at both endpoints.
- Invalid categories (`parse_fail`, `non_monotonic`, `dominance_violation`) are excluded from the primary analysis
  and reported as rates. Truncated responses count as `parse_fail`.
- Item-level exclusion: see Section 4, step 2.
- No other exclusions (no outlier removal).

## 8. Sensitivity analyses (exploratory)

- **S1. Including invalid responses:** for non-monotonic and dominance-violating responses, use the switch point of
  the closest consistent pattern (fewest changed rows). Checks whether excluding invalid responses biases contrasts,
  since interventions may change valid rates.
- **S2.** EV-normalized risk premium instead of range-normalized.
- **S3.** Moderate-probability items (p = 0.3, 0.5, 0.7; 12 items) and extreme-probability items (p = 0.1, 0.9;
  8 items) analyzed separately.
- **S4.** Each version separately; the version-1 minus version-2 difference as a measure of label bias.
- **S5.** Mixed items by elicitation direction (A vs. B); the A minus B difference as a measure of procedure dependence.
- **S6.** Mixed items excluding censored responses.

## 9. Reason analysis (RQ3; exploratory)

1. Read a sample of Reason lines and define 4-6 categories (e.g. computes expected value, avoids risk, refers to
   the example, restates the instruction without following it).
2. Hand-label 30-50 reasons; label all reasons with an LLM; report agreement with the hand labels.
3. Compare category frequencies across conditions and modes.
4. Reason-behavior consistency: how often a stated reason matches the measured choice.
The categories are not fixed in advance; this part is exploratory throughout.
